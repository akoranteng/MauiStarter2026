📘 Module 02 — UI Styling Basics
This module introduces foundational UI styling techniques in .NET MAUI, focusing on building clean, modern, and consistent layouts for mobile applications. The goal is to establish a visual identity for the app while learning how to structure pages, apply typography, and use color effectively.
---
🎨 Styled Pages in This Module
WelcomePage
A modern hero-style landing page featuring:
• Large, bold title typography
• Clean subtitle hierarchy
• Centered layout with balanced spacing
• Consistent color palette
• A primary action button styled for clarity and emphasis
DetailsPage
A polished card-based layout including:
• Page header with title + subtitle
• Rounded-corner card container
• Shadow for depth
• Improved typography hierarchy
• Enlarged “Take Action” button
• Clean spacing and padding for readability
🎯 Module Goals
• Establish a reusable visual style foundation
• Improve readability through consistent typography
• Introduce color palette usage
• Create visually appealing layouts without external libraries
• Prepare the app for more advanced UI modules (animations, Syncfusion components, etc.)
---
🧩 Key Concepts Learned
• Using Frame for card UI
• Applying inline styles safely
• Managing spacing with VerticalStackLayout
• Using color resources (App.xaml or inline)
• Button styling (corner radius, padding, font size)
• Structuring pages for clarity and hierarchy
📂 Files Updated
• WelcomePage.xaml
• DetailsPage.xaml
• (Optional) App.xaml for global styles
---
🚀 Running This Module
From the project root:
dotnet build -t:Run -f net8.0-ios
Or run directly from Visual Studio / VS Code using your MAUI build configuration.
